# Повторный расчёт и сверка с архивом

**Дата:** 30.10.2026. Оригинальные скрипты находятся в `research/original/` и сохранены неизменными. Их исходные пути `/mnt/data/...` заменяются **только во временных копиях**, создаваемых портативным скриптом `scripts/run_research.py`. Архивные CSV не перезаписываются: всё новое попадает в `generated/reproduction/`.

Повторный запуск оригинальных Phase-2 и Phase-2-extra скриптов на проверенном оригинальном пакете `trendfollowing==1.3.1` воспроизвёл **12 CSV и один `data_quality.json`** с точностью `atol=rtol=1e-9` или полностью для текстовых полей. Дополнительный 13-й CSV `signal_definition_robustness.csv` имел формат в архиве **12×8**, но вложенный исходный `phase2_extra.py` записывает под этим же именем краткую таблицу **1×2**. Это пробел в предоставленном архивном коде. Вместо сокрытия различия подготовлен отдельный документированный **новый** скрипт `scripts/reproduce_signal_robustness.py`, реконструирующий COMPOUND и SUM 12-месячные сигналы. Его результаты следует сравнить с исходной таблицей; скрипт **не** объявляется частью замороженного исходного запуска.

Для проверки:

```bash
python -m pip install -r requirements.txt
python scripts/fetch_data.py
python scripts/run_research.py
python scripts/reproduce_signal_robustness.py
python scripts/verify_reproduction.py
python -m unittest discover -s tests -v
```

**Границы:** это воспроизведение расчётов на том же внешнем пакете данных, а не независимая реконструкция от биржевых сделок и котировок. Monte Carlo (`random_sign_placebo.csv`) использует 3000 итераций и фиксированный seed. На слабом ПК расчёт может потребовать заметное время и оперативную память.
