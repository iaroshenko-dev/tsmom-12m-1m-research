# Источник данных

Исторические данные **84 фьючерсов**, дневные USD-returns и оценки торговых издержек взяты из распространяемого на PyPI пакета авторов Artur Sepp и Vladimir Lucic `trendfollowing==1.3.1`.

**Ссылка:** https://pypi.org/project/trendfollowing/1.3.1/

**Оригинальный wheel:** `trendfollowing-1.3.1-py3-none-any.whl`

**SHA256:** `76beb7a35b22cb2784df98bb20a6d9ca5803c4df761398b877db765bd6562c9a`

**Важно:** исходный wheel, его код и данные *не* перепубликуются в репозитории. Для повтора скрипт `scripts/fetch_data.py` загружает именно этот wheel, проверяет SHA256 и распаковывает три CSV в `data/vendor/` (эта папка игнорируется Git). Сама версия 1.3.1 опубликована под `GPL-3.0-or-later`. Более новые версии могут иметь другую лицензию или содержание; **замена версии без повторной проверки недопустима**.

Источник имеет ограничения по составу инструментов, непрерывным контрактам, оценкам издержек и воспроизведению биржевых первичных данных. Подробнее — в итоговом отчёте.
