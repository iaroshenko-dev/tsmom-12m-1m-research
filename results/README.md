# Результаты Quant Research №2 — TSMOM 12m/1m

**Архивный запуск 14 октября 2026 года.**

## Начать с Excel

**[Открыть полную книгу результатов TSMOM (.xlsx)](TSMOM_Results_Reader.xlsx)**

Это **настоящая книга Excel**: 13 CSV импортированы как **13 отдельных таблиц** (а не просто переименованы в `.xlsx`). Значения уже разбиты на столбцы; числовые показатели распознаны как числа, проценты отформатированы, добавлены фильтры и закреплена строка заголовков. Всего 16 листов: обзор, 13 таблиц, словарь английских названий полей и проверка исходных данных.

**Важно для Excel в России:** если открыть исходный `.csv` двойным кликом, из-за регионального разделителя строки могут оказаться в одном столбце. Это не повреждение данных. **Открывайте `.xlsx`**, его вручную конвертировать не нужно.

## Что является исходником

**CSV и JSON — неизменённый архив исходного расчёта.** Они нужны для Python, независимой проверки результатов и сравнения после повторного запуска. Книга Excel — дополнительно подготовленная форма для человека, но не замена машинным источникам. Заголовки колонок переведены на русский **только в Excel**, а названия исходных колонок остаются в отдельном листе «Словарь».

Инструкции по воспроизводимости: [`../docs/REPRODUCTION_AUDIT.md`](../docs/REPRODUCTION_AUDIT.md).
